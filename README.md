# Colonic enterotype-like clusters are associated with distinct fermentation patterns in weaned piglets at two weeks post-weaning
Data and R code for “Colonic enterotype-like clusters are associated with distinct fermentation patterns in weaned piglets at two weeks post-weaning.”

## Contents

- `Raw data/`: datasets used in the analyses
- `R code/`: R scripts for clustering, diversity analysis, ANCOM-BC2, statistical analyses, and figure generation

## Raw sequencing data

The raw 16S rRNA gene sequencing data are publicly available in the NCBI Sequence Read Archive under BioProject accession numbers:

- PRJNA1321873
- PRJNA1480035

## Software

The analyses were performed using R version 4.5.1.
